# 开发辅助工具箱 (tools/)

本目录用于统一收纳本地开发、快捷部署、离线测试及二进制依赖等各类辅助工具与脚本。

## 工具列表说明

- **`start.bat`**：
  一键拉起本地稳定开发服务器的批处理脚本。
  会自动安装必要依赖，一键完成本地 mock API 服务端和前端 Vite 开发服务器的引导，并自动在浏览器中打开工作区。
  
- **`playwright-cli/`**：
  本地存放 Playwright chromium/headless 离线浏览器的二进制缓存工具包目录。

## 运行指南

- 双击运行 **`tools/start.bat`** 即可在本地启动完整的开发服务器工作流。
  批处理内部已针对路径进行了切换适配，可安全地在 `tools/` 文件夹下直接拉起。

## Git 过滤配置

为了确保只向仓库提交轻量的配置和核心运行脚本，避免将庞大的浏览器二进制包（如 `playwright-cli` 内部二进制）提交上去，我们在 `.gitignore` 中进行了防呆忽略设置。
