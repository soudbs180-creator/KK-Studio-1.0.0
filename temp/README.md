# 临时文件与缓存工作区 (temp/)

本目录用于统一放置本地开发、测试及构建期间自动生成的各类临时缓存与静态输出。这使得项目根目录能长期保持核心代码的物理收敛与整洁。

## 子目录说明

- **`playwright/`**：
  放置端到端自动化测试及页面自适应截图、跟踪调试数据。
  由 `scripts/test/verify-*.mjs` 自动写入。
  
- **`kk-local/`**：
  本地 API 开发服务器和 mock 运行时所产生的本地数据库快照、运行日志和临时缓存。
  
- **`scratch/`**：
  AI 助手和开发人员在本地进行临时草稿编码、代码拆解与实验脚本时的工作仓。

- **`build-outputs/`**（可选）：
  编译输出缓存。

## Git 忽略规则

为了防止无用的大二进制缓存或截图被误提交到代码库，除了本 `README.md` 外，本目录下的其它子文件夹在 `.gitignore` 中已被全部忽略过滤。
