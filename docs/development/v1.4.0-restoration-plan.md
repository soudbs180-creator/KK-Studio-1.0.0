# KK Studio v1.4.0 Restoration Plan

This document records the safe restoration strategy for the unfinished `1.4.0` migration captured in `stash@{0}`.

## Current state

- The repository has been safely rebased to the `1.4.0` version baseline.
- Build metadata now emits `version`, `releaseDate`, and `releaseNotes` through `dist/app-version.json`.
- Architecture boundary checks have been upgraded and currently pass with explicit allowlisted migration debt.
- Full verification is currently green: `typecheck`, `architecture:check`, and `build` all pass.

## Guiding principle

Do not restore `stash@{0}` wholesale.

Restore `1.4.0` in batches:

1. Version and release metadata
2. Architecture rules and migration constraints
3. Shared contracts and compatibility layers
4. API module migration
5. Payment-sidecar migration
6. Frontend interaction and animation refinements
