# KK Studio Z-Index 图层层级指南

> 规定画布、卡片节点、悬浮控制台、设置侧边栏及弹窗的严格 Z-Index 范围，防范遮挡。

为了防止画布上多层元素交互产生层级遮挡错误，项目内所有组件的定位必须严格遵循如下 Z-Index 分区：

## 1. 层级划分定义

| 层级名称 | Z-Index 范围 | 典型应用组件 | 核心定位与控制规则 |
|---|---|---|---|
| **画布基层** (Canvas Base) | `1 - 9` | 背景网格线、拖拽绘制层、对齐引导辅助线 | 绝对位于节点后方，不阻碍节点交互 |
| **导线交互层** (Connectors) | `5` | 节点间的关联导线（Connectors） | 便于连线可见且可点，但不能遮盖卡片上的按钮 |
| **节点载体层** (Cards & Nodes) | `10 - 99` | Prompt 卡片容器、Image 图像卡片、多媒体内容节点 | 画布上的普通互动主体，根据选中状态可在 `10-30` 内微调 `zIndex` 提升选区 |
| **悬浮控制层** (Floating UI) | `100 - 499` | Minimap 小地图、Zoom 缩放控制台、画布悬浮操作快捷键栏 | 无论画布如何缩放，必须保持在顶部常驻，不被卡片遮挡 |
| **遮罩抽屉层** (Overlays & Drawers) | `500 - 999` | AI 接管侧边栏、项目管理面板、设置抽屉（Settings Shell） | 拥有独立的系统背景遮罩，处于全屏半透明覆盖态 |
| **模态特权层** (Modals & Menus) | `1000+` | Modal 确认对话框、Toast 全局弹窗通知、Dropdown 右键上下文菜单 | 特权层，必须凌驾于所有常规布局之上 |

---

## 2. 关键开发规约

1. **避免随意的硬编码**：禁止在业务组件中随意设置 `z-[9999]` 或 `z-[100000]`，必须在预设的范围内进行细分。
2. **上下文隔离**：移动端抽屉与设置页在移动设备上的 Z-Index 统一采用 `500` 以上以适应 SafeArea 顶栏覆盖。
3. **右键菜单防遮挡**：上下文菜单 (`Dropdown`) 统一使用 React Portal 挂载到 `document.body` 根节点上，确保 Z-Index 绝对值在 `1050` 以上，防止在大画布缩放状态下被 Canvas 边缘裁切。
